# Quiz Game

# Features
Quiz Scene with 18 Animal Cards, 5 Categorized Attributes

Randomized Category per Session

Card Drag & Drop into Red/Blue Buckets

Pop-up Window with Animal Descriptions

Finish Screen with Score & Incorrect Cards Summary

Smooth Animations, and UI Transitions

# How to Run:
Open the project in Unity 2022.3.21f1.

Go to File → Build Settings.

Select your target platform (Windows, Mac, Android, etc.) and click Switch Platform.

Build and Run the project.

# Controls:

Click or tap on cards to view descriptions.

Drag cards into the red or blue bucket based on the shown category.

# Notes:
No platform-specific code is included. The same logic applies across all platforms.

For mobile builds, ensure touch input is active via Unity’s Event System (no custom platform handling is required).
